<h3 class="pub-title">Designing Code Analyses for Large-scale Software Systems I</h3>
<p class="pub-venue">Master course, Universität Paderborn</p>
<p class="course-desc">This course covers several concepts in static code analysis: intra-procedural data-flow analysis, call-graph construction algorithms, context-insensitivity, pointer analysis, analysis frameworks (IFDS, IDE, VASCO).</p>
<div class="term-tags"><span>Winter 2022</span><span>Winter 2021</span></div>
</article>
<article class="pub">
<h3 class="pub-title">Designing Code Analyses for Large-scale Software Systems II</h3>
<p class="pub-venue">Master course, Universität Paderborn</p>
<p class="course-desc">This course covers several novel, advanced concepts in static code analysis: sparse IFDS, pushdown systems, demand-driven program analysis, hybrid analysis and improved user experience.</p>
